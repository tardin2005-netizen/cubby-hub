# Cubby Hub

**Cubby** é a marca própria da loja de organização: cabos e fios, gavetas e armários, etiquetas.

Este repositório guarda a central da marca num arquivo só (`index.html`). Dá para baixar os logos em SVG e PNG com fundo transparente, ver a paleta, a tipografia e o que pode e o que não pode fazer com o logo. Tudo funciona direto no navegador, sem servidor.

> Tudo no seu lugar, com espaço de sobra.
